BetterCosmic — update host

This GitHub Pages site serves the auto-update manifest for the BetterCosmic Fabric mod. It is machine-facing infrastructure, not a download page.

The mod's UpdateChecker reads the manifest on launch and compares its latest field against the installed version:

👉 manifest.json

Downloads live on the GitHub Releases page. Jars are immutable, versioned assets; this manifest only ever points at the newest one.

Maintainer notes: the manifest is regenerated and committed automatically by the release workflow on every v* tag. To roll back, edit docs/manifest.json to point latest/url/sha256 back to a previous release and push — the old jar is still hosted. Pages must be configured as Deploy from a branch → (default branch) → /docs.
